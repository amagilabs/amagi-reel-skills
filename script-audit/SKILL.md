# script-audit

An audit that lists twelve problems is a way to avoid the one that matters. This ends in ONE fix.

## Before you start

1. Read `voice.md` if it exists (see the voice-editor skill). Judge the script against how this
   creator talks, not against a generic standard.
2. Count the words. At about 150 spoken words per minute, a 30-second reel holds about 75 words.
   Write the estimated runtime at the top of your answer.

## The five beats

Mark where each beat starts in the script. If a beat is missing, say so.

1. **Hook (first 3 seconds).** Does the first line name the viewer's situation or open a question?
   If it opens with a greeting, a name, or "in this video", it fails.
2. **Stakes.** Why should the viewer care right now? What does the problem cost them?
3. **Turn.** The one idea that changes how they see it. If the script has two turns, it has one too many.
4. **Proof.** Something the viewer can see: a screen, a before/after, a real number, a file. A claim
   with nothing on screen is not proof.
5. **One ask.** One call to action. Comment a word, save it, or follow. Not all three.

For each beat, write what is said and what is ON SCREEN. A beat with nothing to look at is a podcast.

## What to check line by line

- Any sentence that restates the one before it. Cut it.
- Any line that announces instead of says ("Here's the thing", "Let me explain", "This is huge").
- Any number or result you can't trace to the creator. Flag it; never keep a made-up figure.
- Any line longer than one breath. Split it.

## What to hand back

1. **Runtime estimate** and word count.
2. **The beat map:** five rows, each with the line, what is on screen, and pass or fix.
3. **The ONE fix.** Name it, say why it is the biggest problem, and show the changed lines.
4. **The rewritten script** with only that fix and any line-level cuts applied. Keep every fact,
   number, and name from the original exactly as written.
5. **What is already working**, two specific items, so the creator doesn't break them.

End with: **record this version, or change it?**
