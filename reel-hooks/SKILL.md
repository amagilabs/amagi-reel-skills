# reel-hooks

The first line decides whether anyone hears the second. This skill writes five options, scores
them honestly, and keeps two. It never hands back a single hook.

## Before you write

1. If a file named `voice.md` exists in the project (see the voice-editor skill), read it first and
   write in that voice. A hook the creator can't say out loud naturally is a bad hook.
2. Ask for the one thing the video delivers if the idea doesn't make it obvious. A hook promises a
   payoff. If you don't know the payoff, you can't write the promise.
3. Never invent a number, a result, a client, or a source. If a figure would make the hook stronger
   and you don't have one, write the hook without it and say what figure would help.

## The patterns

Write one hook per pattern, five patterns per run. Pick the five that fit the idea best.

| Pattern | Shape | Example |
|---|---|---|
| Call-out | Name the viewer's exact situation | "If Claude writes your captions and they all sound the same, this is why." |
| Wrong belief | State a belief the viewer holds, then doubt it | "Better prompts won't fix robotic scripts." |
| Specific result | A concrete outcome with a real number | "I cut my script edits from [X] minutes to [Y]." (use your real numbers) |
| Before/after | Show the bad version, promise the fix | "This is what Claude wrote. Here's what I posted." |
| Open loop | Start a story that only finishes later | "I deleted one line from my prompt and my reels stopped sounding like ads." |
| Warning | A cost the viewer is paying right now | "Every 'Let's dive in' in your script is losing you viewers." |
| List promise | A small, exact number of things | "Three files that make Claude sound like you." |
| Question you can't skip | A question the viewer has asked themselves | "Why does every AI script open the same way?" |

## The rubric

Score each hook 1-5 on each line, then total out of 25.

1. **Specific.** Names a thing, a number, or a situation. "Massive growth" scores 1.
2. **About the viewer.** The viewer can see themselves in it within one read.
3. **Open question.** It raises something the viewer wants closed and can't close without watching.
4. **Matches the payoff.** The video actually delivers what the hook promises. A hook that oversells
   scores 1 here no matter how good it sounds.
5. **Sayable.** Under about 15 words, no filler ("so", "basically", "hey guys"), easy to say in one breath.

A hook with any single score of 1 loses, even with a high total. The weak part is where people leave.

## What to hand back

- All five hooks with their five scores and total, in a table.
- The top two, each with one line on why it fits this idea.
- One line naming the pattern that won.

End with: **use one of these, or change the idea?**

## Rules

- Never open with the creator's name or a greeting.
- Never promise something the video doesn't show.
- One idea per hook. A hook with two promises keeps neither.
