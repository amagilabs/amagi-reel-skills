# AmagiLabs reel skills (free mini pack)

Three Claude Code skills for short-form video scripts:

- **reel-hooks**: five opening lines on five patterns, scored, top two kept.
- **script-audit**: a beat-by-beat review of a reel script that ends in ONE fix and a rewrite.
- **voice-editor**: builds a voice.md profile from your own writing, then edits drafts against it
  with a never-say list and a fact check that keeps your numbers and names intact.

They work together: voice-editor writes `voice.md` once, and the other two read it.

## Install

Copy the three folders into your Claude Code skills folder:

- macOS / Linux: `~/.claude/skills/`
- Windows: `%USERPROFILE%\.claude\skills\`

So you end up with `~/.claude/skills/reel-hooks/SKILL.md` and so on. Start a new Claude Code
session and they load on their own. You can also call them by name, for example `/voice-editor`.

Using Claude.ai instead? Paste a SKILL.md into a Project's instructions. It works, but Claude Code
loads the right skill for you when the task matches.

## Start here

1. Run voice-editor first and give it three to five things you wrote yourself.
2. Ask for hooks: "write hooks for a reel about <your idea>".
3. Paste your script and ask for an audit.

These skills write. You decide what gets posted.
